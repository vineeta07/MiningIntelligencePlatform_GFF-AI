# User Manual
## Mining Intelligence Platform

### 1. Getting Started

#### 1.1 Accessing the Platform
Open your web browser and navigate to:
- **Local:** `http://localhost:3000`
- **Network:** `http://<server-ip>:3000`

#### 1.2 Navigation
The platform has 4 main sections accessible from the top navigation bar:

| Section | Description |
|---------|-------------|
| **Dashboard** | Executive command centre with real-time KPIs |
| **Rock Classification** | Upload rock images for AI analysis |
| **Analytics** | Historical trends and classification statistics |
| **Documentation** | System documentation and technical specs |

---

### 2. Mining Operations Dashboard

The Dashboard is your primary operational view. It provides:

#### 2.1 Production Overview
Six KPI cards showing:
- **Daily Tonnage** — Total output in tonnes
- **Mine Utilization** — Percentage of mine capacity in use
- **Ore Grade** — Average ore purity percentage
- **Equipment Health** — Percentage of equipment operational
- **Energy Draw** — Power consumption in MWh
- **Carbon Footprint** — CO₂ emissions in tonnes

Each card shows a trend indicator (▲ up / ▼ down) compared to the previous period.

#### 2.2 Real-Time KPIs
Four additional metrics: Machine Utilization, Fuel Consumption, Downtime, and Ore Recovery Yield.

#### 2.3 30-Day Production Trend
Bar chart showing daily tonnage over the last 30 days. Hover over any bar to see the exact value.

#### 2.4 Safety Monitor
Real-time safety data: Active Incidents, Days Without Incident, Risk Index, Workers On Site, and per-zone risk levels.

#### 2.5 Equipment Monitoring
Data table showing all tracked machinery with Equipment ID, Name, Type, Utilization %, Fuel Rate, Hours Today, Temperature, and Status.

#### 2.6 AI Insights Engine
Predictive alerts generated by the AI system. Three severity levels:
- 🔴 **CRITICAL** — Immediate action required
- 🟡 **WARNING** — Schedule preventive action
- 🟢 **INSIGHT** — Informational optimization opportunity

### 3. AI Rock Image Classification

#### 3.1 Uploading an Image
1. Navigate to **Rock Classification** from the navbar
2. **Drag and drop** a rock image (JPEG/PNG) onto the upload area, or click to browse
3. The image preview will appear in the left panel

#### 3.2 Adding Geological Metadata
Fill in the optional metadata form:
- **Mine Name** — e.g., "Rajmahal Mine"
- **Region** — e.g., "Jharkhand, India"
- **GPS Latitude/Longitude** — Decimal coordinates
- **Operator Name** — Your name
- **Notes** — Field observations

#### 3.3 Running Classification
Click the **"Classify Rock Sample"** button. The AI engine will:
1. Process the image through the ResNet50 neural network
2. Generate confidence scores for all 7 rock types
3. Create a Grad-CAM heatmap showing what the AI focused on

#### 3.4 Reading Results
- **Classification Result** — The predicted rock type and confidence score
- **Confidence Matrix** — Bar chart showing probabilities for all 7 classes
- **Grad-CAM Analysis** — Three panels: Original Image, Heatmap, and Overlay

#### 3.5 Supported Rock Types
Basalt, Coal, Granite, Limestone, Marble, Quartzite, Sandstone

### 4. Analytics & Reports

The Analytics page shows:
- **Total Classifications** — Cumulative count
- **Class Distribution** — Horizontal bar chart of rock types detected
- **Monthly Trend** — Bar chart of classifications per month
- **Recent Classifications** — Data table of latest results with search

### 5. Troubleshooting

| Issue | Solution |
|-------|----------|
| Dashboard shows no data | Ensure the backend is running (`uvicorn app.main:app`) |
| Classification fails | Check that `best_model.pth` is in the `model/` directory |
| Grad-CAM not generating | Verify PyTorch and OpenCV are installed |
| Images not loading | Ensure MinIO is running and bucket exists |
